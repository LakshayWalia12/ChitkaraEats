🍔 ChitkaraEats

 Campus Food Ordering Website

ChitkaraEats is a campus food ordering website designed to provide students with a convenient way to explore food options, select food items, manage their cart, and proceed to checkout.

 📌 Project Overview

The project aims to simplify the campus food ordering experience by providing an interactive and user-friendly website.

Students can explore food options, view available items, add products to their cart, and enter their details during checkout.

 ✨ Features
- Student Login
- Food Menu
- Food Item Selection
- Shopping Cart
- Quantity Management
- Checkout Page
- Responsive User Interface
- Session Storage for Data Management

 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Session Storage
